# YGPT Local 1.0.12

修复 Chrome/Edge 深层控件扫描。用户反馈的任务实际运行于 1.0.10：桌面授权和后续键盘调用成功；一次未指定控件的 type 调用返回 SELECTOR_REQUIRED，没有相应的键盘安全策略拒绝记录。旧扫描停在第 8 层，却错误报告未截断，扩展卡片上的重载按钮因此不可见。

现在默认读取 32 层、600 个节点，如实报告深度、节点数量及界面变化导致的截断。可通过当前控件选择器只扫描子树，并在限定范围内调整 maxDepth/maxNodes。新增开关状态，便于确认开发者模式；缺少选择器时提供明确提示。

工具说明区分扩展卡片重载和浏览器页面刷新，要求依据实际错误报告权限问题。当前聊天的一次桌面 Full Access 在有效期内继续覆盖后续操作，普通扩展重载不需要管理员权限。

实机独立 Chrome 测试复现了第 8 层漏检，并通过更深层的实际重载按钮，把一次性测试扩展从 1.0 更新到 1.1，确认后台进程重启且扩展保持启用。该测试不代表用户真实 Obsidian Chat Sync 已重载，也不代表 P3R 归档验收通过，仍需在原任务中核验。如果宿主缓存旧工具结构，更新后刷新插件工具列表或新开会话。

已有安装请使用 Update。欢迎在 GitHub Issues 反馈问题。
