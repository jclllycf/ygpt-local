# YGPT Local 1.0.16

普通授权、Full Access 和管理员申请都默认内嵌、详情收起，不自动请求 PiP 或全屏。新卡片仅请求一次恢复内嵌，以清除旧版留下的展开状态，之后保留用户手动展开详情的选择。新版与兼容资源均只声明内嵌模式。

等待批准、以及已批准但仍在执行的响应明确返回 taskPending、continueWaiting、shouldEndTurn: false 和下一步等待指引。模型应继续携带原参数等待，不能把一次有界等待到时当作任务完成，也不应要求用户另发消息才能继续。

卡片区分等待仍有效、已有结果返回、等待结束但尚未返回结果。即使操作已结束，只要续接仍待确认，就继续核对状态；需要时发送一次续接通知，避免重复消息或操作重放。每次授权渲染使用应用自有标识，不再设置 ChatGPT 的宿主组件会话 ID。

卡片精确位置与对话生命周期由 ChatGPT 控制。当前 [OpenAI UI 规范](https://developers.openai.com/plugins/concepts/ui-guidelines)将内嵌卡放在本轮生成正文之前；插件不能插入任意正文段落之间，也不能保证宿主永不结束生成。旧缓存面板可能需要关闭一次。真实宿主验收仍须与组件测试和本机后台验证区分。

桌面 Full Access 仍默认 **100 分钟**。开发机在运行全屏游戏时出现的输入拒绝仍是独立、尚未完成的桌面实测问题，本版不会操作或关闭游戏。
