# YGPT Local 1.0.3：整合 Windows 发布版

[English](RELEASE_1.0.3.md) · [安装指南](SETUP_GUIDE.zh-CN.md) · [清理机制详情](RELEASE_1.0.2_ZH.md)

本版合并安装清理修复与 GitHub 主分支同期收到的 Windows CI、运行时元数据及进程检测修复，保留双方改动。

- 连接与当前程序完整性验证后，保留一个可信回滚点，自动淘汰多余的已验证程序副本及安装目录内的重复下载。
- 失效卸载登记先备份再移除；旧数据目录的卸载请求在停止服务或删除文件前被拒绝。
- 下载清理与缓存清理独立执行。迁移前范围的签名记录明确显示需要复核，不会改绑授权或删除文件。精确登记新更新包后可恢复下载清理。
- 英文清理窗口显示已删除、保留、延期和需复核项目、回收空间及保留的回滚点。私人配置、凭据、状态、快照、迁移/恢复资料及开发仓库受到保护。
- 产品版本递增时保留依赖版本与下载包元数据的一致性。
- 改进 Windows CI 的分支/标签范围、过期构建取消、发行元数据认证与失败诊断，并修复物理路径、私有权限及瞬时 UIA 检测的测试稳定性。
- 忽略无关进程的畸形 WMI 路径；涉及本安装目录而又无法确认的路径继续拒绝维护。

包含此前的浅蓝高清图标、英文引导、独立中文说明、浏览器生命周期修复及更明确的安装、验证、更新、卸载反馈。已有安装使用 Update，新安装使用 Setup。安装器未签名，请核对 `SHA256SUMS.txt`。旧版已加载扩展仍需每个浏览器配置手动 Reload 一次。

本机已安装的 1.0.2 通过文件、身份、ACL、连接与自动清理验证。**按用户最新要求，1.0.3 的本机安装等待后续通知。** [验证记录](../evidence/housekeeping-1.0.3-verification.json) 单独记录源码、测试和发行包证据；不宣称已经完成真实 ChatGPT 人工审批、所有登录态操作、Windows 登录恢复或干净系统验收。
