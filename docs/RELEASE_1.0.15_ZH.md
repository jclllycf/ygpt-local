# YGPT Local 1.0.15

桌面授权成功后，后续键盘调用仍可能失败。旧适配器没有读取 Win32 错误，却把所有 SendInput 未完全成功都标记为 INPUT_BLOCKED_UIPI，可能让已经授权的任务再次索要权限。

新版返回请求/实际送入的事件数量、Win32 错误以及进程完整性级别，区分零事件失败与部分送入。目标权限明确更高时在输入前给出诊断；不会凭零返回值认定 UIPI。组合键的按下与逆序松开一次发送，发送前再次检查交互桌面和前台目标。部分成功或此前已经送入输入后再失败时，结果仍可能不确定，不得自动重放。

桌面 Full Access 仍默认 **100 分钟**，仅限批准的当前聊天，不会提升普通桌面工具的 Windows 权限。可选管理员命令执行器仍需要独立卡片和 Windows UAC。

开发机已用新版诊断复现 INPUT_ACCESS_DENIED：送入零个事件、Win32 错误 5，两端均为普通完整性级别。目前尚未确认是哪一项 Windows 输入条件造成拒绝。因此本版不宣称已解除本机输入阻止，也不宣称另一个扩展的真实聊天验收已完成。

已有安装使用 Update；服务重启后重新选择并绑定当前窗口。欢迎在 [GitHub Issues](https://github.com/jclllycf/ygpt-local/issues) 反馈。
