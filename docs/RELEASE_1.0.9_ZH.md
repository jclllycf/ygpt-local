# YGPT Local 1.0.9

本版修复只读目录大小统计被误要求授权的问题：脚本中的变量、循环和计算不在旧版狭窄的只读分类器范围内，随后对安装目录的引用又命中了旧的路径规则。

在用户指定的默认放行模式下，未知脚本、动态或编码代码、多行参数、受保护目录引用和工作目录位置，都不再单独构成授权理由。脚本无需先证明只读才能运行。明确的破坏性操作、系统或权限变更、敏感位置写入、凭据外传仍需授权；编码 PowerShell 会先解码，再检查相同的具体高危信号。

已对后台保存的实际请求做纯策略对比，结果由“需要授权”变为“允许”，未执行原请求。隔离测试用同类统计脚本读取一次性样例目录，并确认明确的敏感写入仍保持暂停。现有待授权请求会保留，更新不会代选或重放。

已有安装使用 Update 更新，保留密钥、配对、私人数据和快照。Full Access 仍仅限当前聊天。操作说明见[权限指南](CHAT_ACCESS.zh-CN.md)，具体测试与实机范围见发行附件中的验证记录。

同时修复 Windows 短路径别名导致运行时校验误判的问题，仍检查精确哈希并拒绝链接路径。回收站实测从权限测试中独立出来；测试卷没有现有回收站时会明确跳过该环境相关项目。

欢迎通过 [GitHub Issues](https://github.com/jclllycf/ygpt-local/issues) 反馈。附件请先移除密钥、能力令牌和私人信息。
