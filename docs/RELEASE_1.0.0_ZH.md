# YGPT Local 1.0.0 正式版

2026-10-23。正式发布到现有 GitHub 仓库的 Releases，版本标签为 `v1.0.0`，不是预发行版。仓库访问权限保持私有。

[English release notes](RELEASE_1.0.0.md) · [中文安装说明](SETUP_GUIDE.zh-CN.md) · [中文升级说明](UPGRADE_USER_GUIDE.zh-CN.md)

## 本次变化

- 图标底部和双臂的深蓝改为干净的浅天蓝，保留原轮廓、透明背景和黄色日光。应用提供完整色彩的 256 / 512 / 1024 PNG；Windows 图标含 16 / 24 / 32 / 48 / 64 / 128 / 256 七档。
- 授权条主按钮改为浅蓝底、深色文字；图标可解码，实际页面仍执行 CSP，资源地址更新以刷新宿主缓存。历史图标的绿色主题保留。
- 安装和更新引导全英文，统一 Segoe UI Variable 字体、字号和间距。步骤与下一步按钮更直白，文件夹可直接浏览，复制后有确认；外观和高级选项收起，本机工具、Tunnel、首次 ChatGPT 任务分别显示状态。GitHub 默认使用英文说明，中文文件单列。
- 安装完成、验证完成和更新结果使用醒目的独立状态区；处理中显示进度，失败提供明确恢复操作，更新完成后按钮变为 Close updater。卸载展示已删除数、修改或占用导致的残余以及主动保留的私人数据，可打开残余目录、复制详情；本机 `data/uninstall-report.json` 保存结果。卸载辅助程序也留在安装目录内部，作为明确列出的恢复资料，不留后台进程。
- 只有 `assets/brand/plugin-icon-256.png` 是小于 10 KB 的插件表单专用压缩图。桌面、安装器、授权条均使用高清版本。
- 延续 rc.18 的实机修复：数据位于所选程序目录内的 `data`，更新暂存和回退资料位于 `.updates`；隔离读取完成后关闭浏览器并清除临时 Profile；日常浏览器按配置文件、对话隔离接管。

## 下载与升级

已安装的用户运行 `YGPTLocal-Update-1.0.0-win-x64.exe`，首次安装运行 `YGPTLocal-Setup-1.0.0-win-x64.exe`；另有 Portable ZIP。下载后核对 `SHA256SUMS.txt`。安装包未签名。

更新保留配置、加密凭据、Tunnel 连接身份、状态密钥、扩展配对和用户数据，不需要重建 ChatGPT 插件。Windows 快捷方式和计划任务属于操作系统注册项；产品自有数据、缓存、暂存和回退副本均放在安装根目录内。

仍在使用 rc.17 或更早的已加载 unpacked 扩展时，在对应浏览器配置的扩展管理页对 YGPT Local 点一次 Reload，不必重填配对令牌。扩展版本为 1.0.19；未安装该扩展的配置仍需首次安装和配对。

## 验证范围

本次重新执行 Windows 回归、真实 Edge 授权条 CSP/图像检查、按钮文字对比度检查、原生编译和打包检查。结果记录于 `evidence/stable-1.0.0-verification.json`；rc.18 的现场迁移和浏览器验证保留于 `evidence/rc18-verification.json`。

最终 Windows 回归 119 项：114 通过、0 失败、5 项平台条件跳过。新增卸载 fixture 验证正常文件删除、修改或占用文件保留、私人及未知文件保留、可重试和危险清单路径拒绝。

真实 ChatGPT 宿主中的新版展示和真人点击、所有实际登录账户的网页任务、注销/重启恢复及干净 Windows 安装，仍由使用者验收；受控 fixture 不等于真人批准。私人运行状态、凭据、日志和恢复资料不会发布。

## 图像来源

使用内置 imagegen 编辑 `assets/brand/ygpt-glyph-master.png`，再用仓库图标构建脚本导出各尺寸。编辑指令：只将底部与双臂的深蓝改为清透浅天蓝（约 `#94ddfa` 至 `#65bef2`），保留轮廓、比例、位置、白色分隔、黄色日光和透明背景，不增加文字或物体。
