# YGPT Local 1.0.10

本次改进桌面操控、对话内权限启用、授权续接和截图清理，界面继续使用英文。

- 首次桌面绑定或输入只申请一次当前聊天的 **10 分钟 Full Access**。明确确认后，期间的桌面窗口、文件和命令无需重复授权；其他聊天不继承。到期或撤销后，后续输入先暂停等待续期。
- `y_chat_access action=request_full` 直接在当前聊天返回确认卡片，无需 Windows 设置。开发模式仍可自选时长，默认 120 分钟。
- Chrome/Edge 的 invoke 直接使用验证过的实际点击；修正焦点、控件选择、所属弹窗和多显示器负坐标处理。新增 `keys` 键盘快捷键操作。
- 桌面失败保留原生错误码、HRESULT 和结果是否不确定，不再一律误报成权限拦截，也不自动重放不确定动作。
- 新授权使用独立组件实例，在宿主支持时请求画中画悬浮跟随，决定后返回内联；显示后进行有界等待，批准后读取原结果继续。没有等待工具时由卡片发送续接消息；只读桥接失败可安全切换兼容通道，不重发批准动作。
- 截图以内联图片返回，返回前删除本地 PNG，图片内容不写入本地结果历史；启动清理过期的程序生成截图，保留其他图片和私人状态。
- 删除旧工具别名及解析器、重复的授权中心工具；生产环境不再公开桌面测试工具。修正旧 Skill 的过时引用，安装包排除历史工具迁移计划。

独立 Chrome/Win32 实测和隔离桌面测试不等于 ChatGPT 宿主验收。卡片外部位置和生成过程中是否挂载由宿主控制，插件无法强制添加输入框原生菜单；已传给 ChatGPT 的图片遵循宿主保留规则。

已有安装请用 Update。具体测试、本机状态、发行包哈希和未验证范围见附带验证记录。欢迎在 [GitHub Issues](https://github.com/jclllycf/ygpt-local/issues) 反馈，附件请去掉密钥、令牌和私人数据。
