# YGPT Local 1.0.13

The first desktop-control approval now grants **100 minutes of Full Access for the current chat**. The card, server-side duration validation, policy guidance and documentation use the same default. Subsequent desktop actions reuse the grant until expiry or revocation.

Existing grants keep their original expiration time; updating does not extend a previously approved grant. Other chats stay separate. Explicit `y_chat_access` requests retain their configurable duration, and Administrator access remains a separate optional card and Windows UAC confirmation.

Use the Update executable for an existing installation. Feedback is welcome in [GitHub Issues](https://github.com/jclllycf/ygpt-local/issues).
