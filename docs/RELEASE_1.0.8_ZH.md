# YGPT Local 1.0.8

本版减少普通模式的重复授权，并增加仅对一个开发聊天生效的 Full Access。

- 所有结构化读取直接放行，包括受保护路径和修改预览。普通修改保留写前快照；小规模清理在快照验证后移入回收站。敏感修改、大规模删除仍需授权。
- 经安装清单校验的内置运行时，不再仅因位于安装目录就触发授权；参数中的受保护路径和破坏性操作仍会检查。明确只读的 SSH 诊断可携带身份文件参数直接执行。
- 内置 npm/npx 的 Windows 启动器会转换为经过清单校验的 Node 与 CLI 文件执行，修复进程会话和后台任务中的 `spawn EINVAL`，参数保持原样，不增加 Shell 回退。
- 桌面窗口的只读绑定和聚焦直接执行；普通模式下的点击与输入仍需授权。
- 使用 `y_chat_access` 申请、查询或退出 Full Access。开启须在专用卡片中由本人决定，默认两小时、最多十二小时。其他聊天权限不变，已有待授权操作不会自动执行。退出模式或关闭上下文后恢复普通规则。

操作与有效期说明见[权限及 Full Access 指南](CHAT_ACCESS.zh-CN.md)。已有安装使用 **Update** 更新，保留密钥、配对、Tunnel 身份、私人数据和快照。浏览器扩展仍为 1.0.19，无需重新安装。

自动测试覆盖隔离环境中的申请、跨聊天隔离、撤销、过期、受保护读取、写前快照、任务令牌和手机尺寸卡片。测试中的卡片决定属于模拟环境，不代表本轮已完成 ChatGPT 真实点击或 Android 原生客户端验收。具体安装与打包检查见机器可读发行验证记录。
