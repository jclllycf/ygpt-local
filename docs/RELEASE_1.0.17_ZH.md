# YGPT Local 1.0.17

- 所有授权都声明为对话内展示，初始化时就协商 inline，覆盖刷新后先恢复面板、后收到卡片的情况。新卡片详情默认收起；ChatGPT 最终控制外框、准确位置和对话生命周期。
- 新请求等待批准的有效期为 **6 小时**。桌面 Full Access 默认仍为 100 分钟，开发 Full Access 默认 120 分钟，从批准后计算。旧请求保留原到期时间，不复活已过期操作。
- 浏览器工具统一增加页面深度调试与扩展管理。前者支持控制台、网络、JavaScript、页面范围 CDP；后者通过官方 Chrome DevTools MCP 适配器列出、安装、重载、触发和卸载扩展，无需桌面点击。
- 日常 Chrome 的官方调试接入需要本人在 Chrome 开启并确认。YGPT 扩展配对与该连接是独立机制，不能据此推断当前账户/Profile。独立开发浏览器按对话隔离；不复制个人 Profile，不升级或替换 Chrome Use。
- 浏览器等待超时可以继续重查，不再误判为写操作结果未知。桌面输入排队，其他文件、浏览器和进程工作仍可并行；诊断可只读检查前台、按键和权限状态。全屏游戏和 Windows 输入限制仍可能阻止输入，不会靠重复授权或自动提权绕过。
- Windows 授权提醒显示任务简称和请求编号前缀，去重并忽略已经处理的请求。可用 `y_chat_access action=status label=...` 设置简称；系统通知设置可能隐藏提醒。
- 减少“读取受保护路径、另外写普通报告”的误授权。小型可恢复清理扩大到 256 项 / 128 MiB，单文件不超过 32 MiB，保留快照和回收站恢复。受保护写入、凭据上传、重大删除与系统提权仍需审核。

升级后刷新 ChatGPT 当前工具目录。此次隔离测试、Windows CI、本机在线和真实手机/ChatGPT 验收分别记录，不把本机 Ready 当作手机已验收。
