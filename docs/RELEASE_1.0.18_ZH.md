# YGPT Local 1.0.18

新增本机 MCP Client 和 CLI／Agent 调度模块，让普通 ChatGPT 对话发现并调用本机现有能力。

- 五个统一工具负责能力搜索、配置来源管理、MCP 调用、CLI 任务和 Agent 分工。
- 自动读取常见 Agent 的 MCP 配置和 PATH 中的 CLI，按需启动服务；同名服务按来源隔离，不复制或修改原 Agent 配置。
- Codex 沿用选定账号目录、模型、提供方、权限和 MCP 环境；不擅自切换额度，也不继承当前聊天的 Full Access。
- 任务持久运行，可查询进度、读取加密日志、取消和按原会话续接；CLI 会话不会自动变成桌面聊天。
- 临时目录与凭据／审批状态分离，任务结束后回收；结果不确定时不会重复执行。

自动发现有明确范围，不等于扫描所有硬盘或保证所有本机软件均可调用。原配置中已禁用的服务继续禁用。其他 Agent 的非交互参数需要按照本机帮助信息配置。
完整配置与边界见 [Local tools](LOCAL_TOOLS.md)。本版本不把隔离测试、本机连接成功等同于新的 ChatGPT／手机实机验收，也没有启动付费 Agent 测试任务。
