# YGPT Local 当前使用指南

安装见[安装教程](SETUP_GUIDE.zh-CN.md)，权限细节见[当前聊天 Full Access](CHAT_ACCESS.zh-CN.md)。

仅使用当前 tools/list 工具目录。读取、普通修改和未识别到明确高危信号的命令默认放行，文件写入保留写前快照。普通模式下，大规模删除、敏感修改和系统变更需要确认。

首次桌面绑定或输入明确申请一次本聊天的 10 分钟 Full Access。点击确认后，期间本聊天的桌面窗口、文件和命令无需重复授权。其他聊天不继承；用 y_chat_access action=revoke 撤销。

开发时可直接在 ChatGPT 当前聊天说“为当前对话启用 Full Access”。y_chat_access action=request_full 直接返回本聊天内的确认卡片，无需 Windows 设置，开发时长默认 120 分钟。仅查询状态不会发起启用请求。

先显示当前请求的卡片，再用 y_wait_approval 有界等待，保持原任务待处理；本人确认后读取已有结果继续，不得重发原操作。客户端无法挂载时，同一聊天的网页版或 Windows 手动授权中心作为备用入口。

桌面观察主要使用 Windows 控件树。浏览器 invoke 使用验证过的实际点击，keys 支持窗口快捷键。具体原生错误表示执行条件，不代表缺少授权。截图以内联图片返回，返回前删除本地生成 PNG；已送到聊天宿主的图片遵循宿主保留规则。

浏览器默认使用隔离实例；使用日常浏览器时必须选择准确的配对 Profile。后续调用持续携带本聊天 contextToken，不得猜测账户或接管其他聊天的标签页。

结果不确定时先检查效果，不重复执行。保留快照和凭据；安装残留按签名清理记录处理，不全盘扫删。
