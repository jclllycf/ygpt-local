# Current tool catalog

The executable API is the live tools/list catalog. There is no compatibility resolver, old-prefix router or duplicate approval-center tool. Unknown names return NO_TOOL and execute nothing; refresh the catalog instead of translating historical names.

Use y_chat_access for this chat's permissions, y_show_approval for the current request, and y_wait_approval for bounded continuation. Private decision/status tools are component-only. Production does not publish desktop test fixtures.

File, search, project, process, job, browser, desktop and backup tools each use their current typed family. y_ping summarizes the catalog; y_policy explains current rules. See [current user guide](UPGRADE_USER_GUIDE.md).
