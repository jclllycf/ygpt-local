# YGPT Local 1.0.19

授权资源在加载前明确声明首选内嵌显示，并使用新的资源地址避开旧卡片缓存。
旧资源地址仍返回当前组件。

- 兼容接口静默忽略请求时，不再阻止标准 MCP Apps 桥接完成显示协商。
- 显示请求增加超时和有限重试；协商过程中发生的宿主状态变化不会丢失。
- 接口回复内嵌但宿主仍报告展开时，继续处理展开状态。关闭显示区域不会提交授权。
- 普通、桌面、Full Access 和管理员授权共用此逻辑；权限范围、六小时请求有效期和
  一百分钟桌面权限不变。
- 浏览器扩展新增可选的 ChatGPT 显示辅助。启用时由用户授予 `chatgpt.com` 脚本权限；
  只关闭同时具有已知授权标题与 YGPT 图标的查看器。即使组件未加载也可处理，
  不读取聊天正文、不发消息、不提交授权，不扩大浏览器工具中继的个人标签页访问。

真实 ChatGPT 网页曾在刷新后恢复独立查看器，且组件加载失败时仍保留右侧大框。
组件未加载时，服务端组件代码无法执行，也不能直接清除宿主保存的查看器状态。
显示辅助在缺失组件的框架外工作，但隔离测试通过仍不等于真实宿主已通过验收；
实际状态以验证记录为准。此辅助适用于 Chrome/Edge 网页，不适用于原生手机或桌面应用。
