# YGPT Local 1.0.20

Setup 新增 **Account connections**。第二个 ChatGPT 账号填写名称、专用 Tunnel ID
和 API Key 后，即可复用当前安装，无需重复下载或安装。

- 最多八个账号连接同时在线，共用程序、引擎、浏览器中继和 Update 更新。
- API Key 分别使用 Windows DPAPI 加密；原账号的连接和凭据保持原位。
- 会话、Full Access、授权决定和保留的调用结果绑定各自的连接。
- 单个隧道失败独立处理；修改或停止现有连接会等待任务和待授权操作结束。
- Setup 统一提供列表、状态、编辑、替换密钥、连接和停止入口。

在第二个 ChatGPT 账号中，仍需使用其专用 Tunnel ID 安装个人插件，并由本人完成
ChatGPT 的确认。API Key 只填在本机 Setup，不要发送到聊天。
隔离回归测试与真实账号验收分别记录，Connected 仅代表本机隧道就绪。
该版本包含 1.0.19 的内嵌显示修正。所有者已确认浏览器辅助功能能自动关闭
恢复的 YGPT 大框、不影响对话内容，并授权发行。这是用户报告的网页端验收，
不代表原生手机或桌面 App 已通过同样验证。

浏览器工具支持自有标签页交互、控制台、网络记录、JavaScript 和标签页级 CDP。
独立开发浏览器实测通过扩展安装、列举、重载、触发和卸载。现有个人浏览器的
扩展管理仍需要 Chrome 独立调试确认；YGPT 配对或 Full Access 不会自动授予它。

发行包保持已在本机安装并校验的候选包原始字节，校验值见
`evidence/multi-connections-1.0.20.json`；本次文档晋级不修改运行时代码。
完整本地测试为 196 项通过、14 项跳过、0 失败；另一次浏览器专项测试 8/8 通过。
第二账号真实 ChatGPT 调用、原生 App 显示、管理员/UAC 和干净虚拟机验收仍需
分别验证，不以回归测试或本次大框反馈代替。
