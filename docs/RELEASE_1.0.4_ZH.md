# YGPT Local 1.0.4：更清晰的引导与准确文件清理

[English](RELEASE_1.0.4.md) · [安装指南](SETUP_GUIDE.zh-CN.md) · [验证记录](../evidence/setup-1.0.4-verification.json)

全英文向导调整为九步，版本信息固定在左下角，统一 Segoe UI 字体与层级。安装成功后 Back 再返回，设置不变时直接继续；只有改动设置才显示 Apply changed settings 并应用一次。

- Windows 剪贴板被临时占用时重试，持续占用时给出可恢复提示，保留当前进度。
- 独立 assets/plugin-icons 文件夹提供五款 256×256 PNG，每款低于 10,000 字节。引导复制匹配图标路径，只打开专用文件夹；其他界面和 Windows 图标保留高清。
- 图标/授权预览与 field by field 默认展开，复制按钮紧邻对应字段。准确下载文件的自动删除默认勾选，可取消。
- Browser (optional) 独立且可跳过，提供 Chrome/Edge 扩展管理页、扩展目录与配对页按钮。
- 最后一步打开预填英文检查请求的新 ChatGPT 草稿，由用户自行发送，不再依赖复制首次任务。
- 打开该草稿并完成认证标记读取后，默认清理可自行关闭下载的 Setup，即使未点击 Finish setup。安装目录内经过哈希校验的短时助手等待退出，再删除签名计划登记的准确文件，随后退出。空的自有验证目录也会移除。

清理保留 Settings、运行时、凭据、私人数据、快照和可信回滚，继续执行文件身份、完整性、引用和连接健康检查。收据区分实际删除、等待和跳过；不扫用户 Downloads/Temp 或开发目录。

2026 年 10 月 23 日，所有者报告已在 **ChatGPT Free 免费账户**中实际使用成功，为产品定位和可行性增加了用户实测证据。该结果与自动化 fixture 分开记录，不代表所有免费账户/工作区均有相同入口和权限。

编译后的真实 WPF 页面、复制重试、草稿 URL 编码、返回不重复安装、可选浏览器按钮和退出后清理均使用隔离 fixture 验证，不访问用户剪贴板、不发送聊天、不代点批准。最终浏览器输入框的预填仍需在用户选定的登录浏览器中验收。按用户要求，本机生产版更新继续暂缓；干净 Windows、注销登录恢复及各账户/浏览器流程单独验收。

首次安装用 Setup，已有安装用 Update；核对 SHA256SUMS.txt，安装包目前未签名。[欢迎反馈](https://github.com/jclllycf/ygpt-local/issues/new)，请提供版本、复现步骤和脱敏截图，避免密钥、令牌与私人内容。
