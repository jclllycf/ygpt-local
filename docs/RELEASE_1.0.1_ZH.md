# YGPT Local 1.0.1 · 安装清理修复

[English release notes](RELEASE_1.0.1.md) · [中文安装](SETUP_GUIDE.zh-CN.md) · [上一正式版](RELEASE_1.0.0_ZH.md)

已安装使用 `YGPTLocal-Update-1.0.1-win-x64.exe`，首次安装使用 Setup；核对同版 `SHA256SUMS.txt`。安装包未签名。

- 清理器识别实际使用的 `.updates/<事务>/previous`，修复只搜索旧 `.previous-*` 布局的问题。
- 验证当前程序完整性和连接健康后，保留最新一个完整、哈希正确的回滚副本，删除多余的已验证旧程序。修改、联接、共享、未知或正在被引用的文件保留并注明原因。
- 安装目录内部的重复更新包只有在记录的 SHA-256 一致、未被进程或启动项引用时才删除。没有可信回滚副本时保留缓存供修复。
- 旧卸载登记先备份，再按产品、路径身份和数据目录状态精确判断。当前登记、其他仍存在的安装、未知命令、离线磁盘保留；不运行旧卸载命令。备份位于内部 `.updates/registry-backups`。
- 卸载入口若指定旧数据目录，会在停止当前连接或删除程序文件之前被拒绝，防止误点旧登记影响正在运行的新版本。
- 旧下载清理收据的 Complete 不再阻止新更新包清理。外部下载文件必须在更新器勾选删除该确切文件，验证完成且窗口退出后才删除；不扫描清空 Downloads。

设置的 Advanced maintenance → **Review installation leftovers** 可查看候选、保留原因、回收空间、已修复登记和保留回滚点，也可重新执行安全清理。私人结果保存在 `data/installation-housekeeping-receipt.json`。现有 Watchdog 在连接健康后检查、对待处理项重试；缓存未变化时复用检查结果，不持续重复哈希大量文件。

私人配置、凭据、状态库、受保护快照、迁移记录和恢复资料保留。开发仓库及其 dist、外部测试目录不由消费端安装器删除。名为 recovery 的目录也可能仍是当前 Git 工作树的主仓库，必须核实依赖。

删除、保留、延后和需人工检查分别记录；本机 Ready 不等于真实 ChatGPT 真人批准验收。验证记录见 `evidence/housekeeping-1.0.1-verification.json`。

1.0.0 的高清浅蓝图标、英文引导和安装/更新/验证/卸载结果反馈均保留。浏览器功能及配对保留；rc.17 或更早的旧扩展仍已加载时，每个配置需 Reload 一次。
