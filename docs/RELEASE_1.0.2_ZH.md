# YGPT Local 1.0.2：迁移后的自动清理修复

[English](RELEASE_1.0.2.md) · [安装指南](SETUP_GUIDE.zh-CN.md) · [完整清理策略](RELEASE_1.0.1_ZH.md)

本版补齐 1.0.1 的自动清理流程。最终实机检查发现：旧版本的下载清理记录仍指向迁移前的数据目录。所有权检查正确阻止了删除，但抛出的异常也跳过了后续的更新缓存清理。

- 下载文件清理与回滚缓存清理分别执行，一方失败不会中断另一方。
- 旧范围的签名记录明确显示“需要复核”，不会把旧授权自动改绑到新目录，也不会依据这条记录删除文件。
- 清理审查窗口显示保留原因及下一步。通过更新器的精确文件复选框登记新下载后，下载清理可以继续；同一旧记录不再反复尝试。
- 保留一个通过哈希验证的回滚点，淘汰多余的已验证副本及安装目录内的重复下载。失效卸载登记先备份再移除。私人配置、凭据、状态、快照、迁移与恢复记录及开发仓库受到保护。

已有安装使用 Update，新安装使用 Setup。安装器未签名，请核对 `SHA256SUMS.txt`。本版包含英文引导、独立中文文档、浅蓝高清图标、浏览器生命周期修复，以及更明确的安装、验证、更新、卸载反馈。仍加载 rc.17 或更旧代码的浏览器扩展，每个配置需要手动 Reload 一次。

[验证记录](../evidence/housekeeping-1.0.2-verification.json) 区分自动化测试、本机证据和未验证事项。本地就绪与受控浏览器测试不能替代真实 ChatGPT 人工审批、所有已登录浏览器操作、干净 Windows 安装及登录恢复验收。
