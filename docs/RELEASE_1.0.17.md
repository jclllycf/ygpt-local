# YGPT Local 1.0.17

- Keep every approval inline, including desktop, Full Access and Administrator. The MCP Apps initialization now declares inline-only support and negotiates the mode before card metadata arrives, including on refresh. Details stay collapsed for each fresh card. ChatGPT still controls its shell, exact placement and response lifecycle.
- New pending approvals remain valid for **six hours**. Desktop Full Access still defaults to 100 minutes; development Full Access defaults to 120 minutes, starting after approval. Existing requests retain their recorded expiry; expired requests are never revived.
- Add `y_browser_debug` for in-memory console/network records, JavaScript and tab-scoped CDP. Network capture supplies request IDs for reading response bodies. Output is bounded and automatic records omit headers/query strings. Closing the tab releases its observations.
- Add `y_browser_extensions` with the bundled official Chrome DevTools MCP adapter: list, install, reload, trigger and uninstall. A private developer browser is separate per chat. Connecting daily Chrome requires its official debugging setup and the owner's Chrome confirmation; YGPT relay pairing alone does not enable it or identify its profile. Browser/Chrome restrictions remain applicable; this does not promise unrestricted access to every browser feature.
- Return browser wait timeouts as safe, repeatable observations rather than uncertain mutations. Extension transport failures preserve uncertain effects and are never replayed automatically.
- Serialize desktop input across chats while allowing independent browser/file/process work. Read-only desktop diagnostics expose foreground, modifier and integrity information without injecting input. Fullscreen games and Windows input restrictions can still prevent input; another approval does not cure them.
- Add quiet Windows approval notifications with a short chat/task label and request prefix. Duplicates and already resolved requests are suppressed. Use `y_chat_access action=status label=...` to name the task; labels grant no authority. Windows notification settings can suppress balloons.
- Reduce false approvals for protected reads followed by unrelated report writes and exact ordinary file cleanup. Recoverable small cleanup expands to 256 entries / 128 MiB, with 32 MiB per file, protected snapshots and the Recycle Bin. Protected writes, credential uploads, bulk destructive and privileged changes still require review in Standard mode.

Update with the Update executable, then refresh the current YGPT tool catalog in ChatGPT. No Chrome Use upgrade, personal profile copy, credential reset or automatic Windows elevation is performed. Legacy component addresses serve the current component; retired tool names remain removed.

Validation distinguishes isolated browser/extension tests, Windows CI, installed readiness and real ChatGPT/mobile acceptance. The owner's earlier mobile success is retained as reported evidence; this release does not claim a new mobile acceptance run.
